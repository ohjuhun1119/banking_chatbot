# 은행 고객 문의 분류·답변 챗봇 

## 개요

| 항목 | 내용 |
| --- | --- |
| 문제 | 은행 고객 질문을 상담 주제로 분류하고, 주제별 지침에 맞는 안내 답변을 생성 |
| 입력 | 고객 질문 1개 |
| 출력 | 상담 주제, 확신도, 안내 답변 (질문 1개 → 응답 1개) |
| 분류 | 은행 업무 10종 + 업무 외 (총 11종) |
| 데이터 | AI Hub 금융분야 고객상담 데이터 중 은행 라벨링 데이터 + 직접 설계한 업무 외 질문 |

## 데이터

- 출처: [AI Hub 금융분야 고객상담 데이터](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&dataSetSn=71926&topMenu=100), 은행 라벨링 데이터 (Training 40,000 + Validation 5,000)
- 사용 조건: AI Hub 이용정책에 따라 원본·가공 데이터는 저장소에 포함하지 않음. 각자 AI Hub에서 승인받아 내려받아 사용
- 업무 외 질문: `build_out_of_scope.py`로 직접 설계한 템플릿에서 5,000건 생성 (일반 3,500, 금융 단어가 들어간 어려운 예시 1,500)

원본 JSON을 아래 위치에 넣은 뒤 프로젝트 루트에서 순서대로 실행합니다.


| 단계 | 처리 | 결과 |
| --- | --- | --- |
| 추출 | 질문 단위로 6개 컬럼 추출 | 45,000행 |
| 업무 외 생성 | 템플릿 68묶음에서 서로 다른 질문 5,000개 | 5,000행 |

| 분할 | `source_id` 묶음 단위, 주제 비율 유지 80:10:10 | 39,844 / 4,983 / 4,982 |

## 분류 모델 결과

| 모델 | validation Macro F1 | test Macro F1 | test Accuracy | CPU 추론 (배치 1) | 크기 |
| --- | --- | --- | --- | --- | --- |
| TF-IDF + 로지스틱 회귀 | 0.7040 | 0.7031 | 0.7782 | 0.0002초 | 7MB |
| **klue/bert-base (선정)** | **0.7274** | 0.7287 | **0.8143** | 0.014초 | 423MB |
| kakaobank/kf-deberta-base | 0.7243 | 0.7351 | 0.8113 | 0.028초 | 712MB |

- **선정:** validation Macro F1 최고(klue/bert-base)와 1%p 이내인 kf-deberta 중 CPU 추론이 빠른 klue/bert-base
- **test:** 세 모델 모두 validation과 비슷해 묶음 단위 분할에서 평가가 안정적이었다. kf-deberta가 test에서 0.64%p 높았지만, 대부분 표본 18건인 기타(은행)에서 1건을 맞힌 효과이며 이를 제외하면 klue/bert-base가 근소하게 높다. 사전에 정한 규칙대로 test 결과로 선정을 바꾸지 않았다.
- **남은 약점:** 대출문의 ↔ 이자/연체금액 혼동(약 225건), 기타(은행) 미분류. 금융 특화 모델로도 개선되지 않아 라벨 경계의 모호성으로 판단 ([추가 실험](docs/experiments/kf_deberta.md))
- **업무 외:** 템플릿 기반 test에서는 거의 완벽했지만, 직접 작성한 확인용 질문에서는 베이스라인이 40개 중 22개만 검출. 사전학습 모델도 일부 은행 질문을 업무 외로 오차단해 서비스에서 보완

## 생성 모델 비교

| 항목 | GPT-5.6 Luna (선정) | Qwen 2.5 7B (로컬) |
| --- | --- | --- |
| 사용 가능한 답변 (30개) | 30 | 20 |
| 은행 업무 (24개) | 24 | 14 |
| 생성 시간 중앙값 | 2.6초 | 4.3초 |
| 1,000건당 비용 | 약 $0.45 | 장비·전력 |

- 직접 작성한 질문 30개(은행 24, 업무 외 3, 의도 불명 3)를 같은 프롬프트로 두 모델에 보내고, 모델을 가린 채 0~2점으로 채점
- 프롬프트는 개발용 질문 10개로 3회까지만 수정한 뒤 확정하고 최종 질문을 1회 실행
- 두 모델 모두 업무 외·의도 불명은 정확히 처리했지만, 로컬 모델은 구어체 은행 질문을 의도 불명으로 판단하거나 정책의 "~할 수 있다"를 단정하는 경우가 있었음
- **한계:** 상용 모델 선정으로 고객 질문이 외부로 전송됨. 질문 30개, 1회 실행 기준이며 채점은 AI 1차 채점 후 본인 검토

### 설계 판단

- **공백 정리 후 정제:** 개인정보 마스킹이 지워지며 생긴 연속 공백 때문에, 같은 질문이 다른 질문으로 취급되는 경우를 함께 걸러냄
- **묶음 단위 분할:** 같은 상담에서 나온 질문, 같은 템플릿에서 나온 업무 외 질문이 학습과 평가에 나뉘어 들어가지 않도록 함. 분할 간 겹치는 `source_id` 0개
- **업무 외 질문 설계:** 길이와 말투를 다양하게 하고 금융 단어가 들어간 어려운 예시를 포함해, 모델이 말투나 단어만으로 업무 외를 구분하지 않도록 함

### 한계

- 기타(은행)는 검증·테스트에 각 18건으로 성능 평가가 불안정함
- 업무 외 질문은 템플릿 기반이라 실제 사용자 질문보다 다양성이 부족함. 템플릿과 무관하게 직접 작성한 확인용 질문으로 별도 검증 예정
