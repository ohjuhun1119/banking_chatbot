# 추가 실험: 금융 도메인 사전학습 모델

## 동기
klue/bert-base는 베이스라인보다 Macro F1이 2.34%p 높았지만,
대출문의 ↔ 이자/연체금액 혼동이 236건으로 전체 오분류(약 925건)의 약 25%를 차지했다.
거래내역 → 이자/연체금액(60건)까지 포함하면 금융 개념이 겹치는 주제 사이 혼동이 가장 큰 약점이다.

## 가설
범용·금융 말뭉치로 사전학습한 kakaobank/kf-deberta-base는
금융 용어와 개념의 관계를 더 잘 이해해, 이 혼동을 줄이고 은행 10종 Macro F1을 높일 것이다.

## 방법
- 모델: kakaobank/kf-deberta-base (MIT 라이선스)
- klue/bert-base와 같은 분할, 같은 학습 설정 (max_length 128, batch 32, lr 2e-5, 3 epoch)
- 같은 평가 지표, 특히 대출문의 ↔ 이자/연체금액 오분류 수를 비교
